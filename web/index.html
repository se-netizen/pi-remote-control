πPi Remote
Sesi

Pi tetap berjalan di komputer walau terminal ditutup, dan bisa dikendalikan dari sini. Kembali ke terminal dengan /remote-control attach.

Sedang berjalan

Perangkat yang terhubung ke Pi ini. Cabut akses perangkat yang tidak Anda kenal. Dari terminal: /remote-control devices.

Model per peran

Profil model dan effort untuk worker orchestrator. Kosongkan provider/model untuk mengikuti konfigurasi Pi.

Model tersedia

Jalankan beberapa worker Pi pada worktree terpisah. Butuh daemon yang dijalankan dengan --workspace.
